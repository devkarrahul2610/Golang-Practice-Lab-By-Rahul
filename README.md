"In Go, composition means creating complex types by combining smaller ones. Instead of saying Dog extends Animal, I say Dog has an Animal. Go achieves this by struct embedding — if I embed a struct, its methods are promoted to the outer struct. For example, a Car can embed an Engine and reuse its Start method. This avoids rigid hierarchies, promotes loose coupling, and makes code more reusable. In practice, I’ve used composition in a logging system where services embedded a common BaseLogger and extended it with file or cloud logging, which made the design flexible and easy to extend."
